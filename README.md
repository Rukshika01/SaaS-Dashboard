# Flow — SaaS Dashboard

A modern **Project Management & Productivity SaaS Dashboard** designed for teams to manage projects, tasks, deadlines, team activity, and productivity in one place.

## ✨ Features

* 📊 Interactive productivity dashboard
* 📁 Project & task management
* 👥 Team management
* 📅 Calendar & deadlines
* 📈 Analytics & data visualization
* 💬 Team messaging
* 🔔 Notifications
* 🌙 Light & dark mode
* ⌘ Command palette
* 📱 Responsive design
* ✨ Smooth animations & micro-interactions

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion
* Lucide Icons
* Charting Library

## 🤖 AI-Assisted Development

**Built entirely using Pi.dev** as an experiment in AI-assisted software development.

The project was designed, developed, refined, and tested using AI as a development partner, exploring how modern AI tools can be integrated into the frontend development workflow.

> **Testing AI-driven development as the future of building software.**

## 🎨 Focus

**UI/UX Design · Frontend Development · AI-Assisted Development · Responsive Design · Data Visualization**

## 💾 Project Type

Frontend-only portfolio project using mock data and local storage.
